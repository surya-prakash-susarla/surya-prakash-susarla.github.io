# surya-prakash-susarla.github.io

Redirects all visitors to [suryasusarla.com](https://suryasusarla.com).

`docs/index.html` is served by GitHub Pages (configured to serve from `docs/` on main). It performs a client-side redirect to `suryasusarla.com`. `docs/404.html` handles any unknown paths the same way.
